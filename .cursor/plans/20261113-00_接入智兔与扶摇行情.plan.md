# 接入智兔与扶摇行情

## 背景 / 目标

Alpha 目前使用 Tushare 提供股票主数据、交易日历、日线和增强数据。本次接入智兔股票列表、快照和单股历史行情，并使用扶摇补充交易日历、全市场日线和可核实的增强数据。关联 [Tushare 数据接入记录](./20261022-00_Tushare数据接入扩展与Runner部署.plan.md)。

## 任务分解（checklist）

- [ ] 核验两个服务的权限、字段、数据日期和单位，并确认全市场导出可下载。
- [ ] 将已验证的数据接入现有行情客户端和同步入口，沿用 SQLite 的数据来源记录及降级机制。
- [ ] 在本地 Conda 环境配置凭据，完成字段转换、降级和同步验证，更新 README。
- [ ] 合并到指定仓库的 `main`，跟踪 GitHub Actions 部署并检查线上页面、API 和静态资源。

## 验收标准

- 已配置的智兔和扶摇凭据可通过正常入口取数，密钥仅通过运行环境提供。
- 数据在上海交易日归档，成交量、金额和复权口径符合 Alpha 现有存储约定。
- 批量日线和单股日线分别使用对应接口。未获权限或口径未验证的数据保留现有降级行为。
- 相关测试通过，线上运行目标提交并通过冒烟检查。

## 风险与回滚

扶摇复权导出是除权除息事件，需要校验推导口径后才能用于历史收益计算。行情接口返回空数据、旧日期或权限错误时继续使用已有来源，保留正确的来源标记。撤销新增数据源环境变量即可恢复原选择顺序。
